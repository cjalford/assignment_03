What I learned:
- A Streamlit script does not run continuously. It executes top to bottom and reruns from line 1 on every time. which resets vaiables
- To keep alues that need to remain you have to use st.session_state with an if statement to not have the value reset when the script reruns
- A gaurd stops the script from running until the widget inputs a value preventing blacks from being returned
- Making the process button triggered makes it so that the same file isn't repeatedly used over and over and the script is only rerun when the button is clicked.
- The Streamlit server process has to stay running in the terminal. When I stopped it, the browser tab had nothing to connect to and showed a blank page.
